ROSALES MADS-BOX paper — ANALYSIS SUMMARY


STAGE 1 — GENOME RETRIEVAL AND ANNOTATION
------------------------------------------
1. Chromosome-level genome assemblies for the ten target Rosales species were
   downloaded from NCBI where available (accessions in Supplementary Table 1).
2. For species without existing gene models, structural annotation was done
   with BRAKER3 (ProtHint + GeneMark-EP+ + AUGUSTUS), run inside a Singularity
   container against the OrthoDB Viridiplantae protein set.
       Script: 01_Braker_genome_annotation.sh (SLURM batch job)
       Input:  soft-masked genome FASTA + Viridiplantae_processed1.fasta
       Output: .gff3 / .aa / .cds gene models
       -> saved to: Supplementary_files/annotations/ (Artocarpus_heterophyllus,
          Eleagnus_mollis, Morus_alba, Urtica_urens — the four in-house-annotated
          genomes)


STAGE 2 — MADS-BOX GENE FAMILY IDENTIFICATION
------------------------------------------------
3. HMMER search of each proteome against the SRF-TF (MADS-box) Pfam profile
   (PF00319.hmm), E-value threshold 0.1.
       Script: 02_hmmer_script.sh (SLURM array job, one task per species)
       Output: <species>_hmmer.txt hit tables
4. Where a gene had multiple isoforms, the lowest-e-value isoform was kept and
   its sequence extracted from the proteome FASTA.
       [CUSTOM, not in Scripts/] — species-specific extraction scripts, tailored
       to Gnomon/GenBank/BRAKER header formats (see e.g. cannabis/ and ulmus/
       "extracted_putativeMADS.fasta" for worked examples)
5. Confirmation of the conserved MADS (M) domain with InterProScan v5.69.101
   (Pfam/SMART/CDD applications).
       Script: Interproscan.sh (SLURM array job, one task per species)
       Output: <species>_interpro.tsv
6. A second HMMER pass with the K-box Pfam profile (PF01486.hmm) on the
   confirmed hits to isolate Type II MADS-box genes.
       Script: 02_hmmer_script.sh, re-run with the K-box HMM (see comment at
       end of script: "repeat with k-box Pfam Hmm")


STAGE 3 — CLASSIFICATION BY PHYLOGENY
------------------------------------------
7. Type II MADS-box protein sets from each species aligned together with
   Arabidopsis thaliana Type II MADS-box references (TAIR) using MAFFT
   (default parameters).
       Script: 03_mafft_alignment.sh
       Output: alignments/*.aln.fasta
8. Alignment trimming with trimAl (-gt 0.9), followed by manual inspection.
       Script: trimal.sh
       Output: alignments and trees_forclassification/alignments/*.gt09.fasta
9. Maximum-likelihood trees in IQ-TREE3 (-m TEST for ModelFinder, -bb 1000
   ultrafast bootstrap), rooted with Oryza sativa MADS14.
       Script: iqtree_phylogeny.sh (SLURM array, one tree per species/family)
       Output: alignments and trees_forclassification/trees/*_iqtree.treefile
10. Trees visualized in iTOL v6; floral MADS-box orthologs assigned by clade
    placement (>50% bootstrap support with a known Arabidopsis protein).
       [EXTERNAL] — iTOL
11. Orthology calls cross-checked with reciprocal best-hit BLASTP against
    A. thaliana floral (A/B/C/D/E) MADS-box proteins.
       Script: reciprocal_blast.sh (SLURM array, one task per species)
       Output: rbh/arabidopsis_vs_<species>.blastp.tsv and
               rbh/<species>_vs_arabidopsis.blastp.tsv
       Two-way (reciprocal) hits parsed out with a custom bash script.
       [CUSTOM, not in Scripts/]
12. Confirmed floral orthologs re-aligned, re-trimmed, and re-run through
    IQ-TREE by MADS-box class (A, B-AP3, B-PI, C/D, E) for the final
    classification trees used in the manuscript figures.
       Data: alignments_and_trees_mads_groups/ (A_genes, ap3, cd, pi, sep —
       .aln.trimal.fasta + matching .iqtree files)


STAGE 4 — CONSERVED MOTIF ANALYSIS
------------------------------------
13. Conserved protein motifs identified with MEME (protein mode, zoops model,
    10 motifs, width 4–60).
       Script: meme.sh
       Output: meme.xml, visualized alongside the phylogenetic tree in iTOL v6
       [EXTERNAL viewing step] — iTOL


STAGE 5 — COLLINEARITY / SYNTENY ANALYSIS
--------------------------------------------
14. GFF3 annotations parsed into MCScanX's 4-column format (chromosome, gene
    ID, start, end), chromosome names prefixed with a 2-letter species tag,
    then concatenated across species.
       [CUSTOM, not in Scripts/] — gff_for_synteny.py / gff_for_synteny_ncbi.py
       (see genome_studies/mcscan_intermediate_files/synteny_plot/)
15. All-vs-all protein alignment (all species + A. thaliana + V. vinifera) with
    DIAMOND blastp (--max-target-seqs 5, --evalue 1e-10).
       Script: forMCScanX.sh
16. MCScanX run with default parameters on the combined positional +
    homology files to call intra-/inter-genomic collinear blocks.
       Output: .collinearity / .tandem files
17. Floral MADS-box gene IDs (from Stage 3) matched against the .collinearity
    file to flag MADS-containing collinear blocks.
18. Macrosynteny ribbon plot (genomes ordered by phylogeny, V. vinifera as
    outgroup), MADS-box blocks highlighted.


STAGE 6 — PETAL (B-CLASS) TETRAMER STRUCTURAL MODELING
-----------------------------------------------------------
19. PI–AP3–AP1–SEP3 tetramer structures predicted with AlphaFold3, both as
    protein-only models and as protein-DNA complexes (63-bp CArG-box DNA
    duplex, chains E/F), for 5 petalous + 6 apetalous species. 5 models per
    complex; highest-pLDDT relaxed model kept for analysis.
       [EXTERNAL] — AlphaFold3 server
       Output: relaxed_model_*.pdb per species, under
       alphafold_contact_summaries/alphafold/tetramer only/<species>/ and
       .../protein-dna/6 turns/folds_2026_06_26_14_57/<species>/
20. Buried surface area (BSA/SASA, Shrake-Rupley) and contact classification
    (H-bond, salt bridge, hydrophobic, van der Waals, clash) computed for all
    6 protein-protein interfaces (+2 protein-DNA interfaces for the DNA
    models).
       Script: analyze_interfaces_fromaphafold.py (Python 3, Biopython)
       Output per species: interface_areas.txt, contacts_<pair>.tsv,
       residues_<pair>.tsv, summary_<species>.txt
       Output overall: summary_interface_areas.csv, summary_contact_counts.csv
21. Structures visualized in ChimeraX.
       [EXTERNAL] — ChimeraX
22. Interface areas plotted as faceted dot plots (tetramer-only figure and
    protein-DNA figure), petalous vs. apetalous species compared.
       Script: Dotplot_figures.R (reads the two summary_interface_areas.csv
       files produced in step 20)
       Output: fig_dotplot_tetramer.pdf/png, fig_dotplot_proteindna.pdf/png


SUMMARY FIGURE: MADS-BOX ORTHOLOG COUNTS
-------------------------------------------------------
23. Final counts of A/B/C-D/E class floral MADS-box orthologs per species
    (from Stage 3 classification) compiled into mads_box_data.csv and plotted
    as a grouped bar chart, faceted by plant family.
       Script: mads_box_barplot_pub_2.R
       Output: mads_box_barplot_pub.png / .pdf
